## ⚠️ Current status: NOT SUBMITTABLE

A blocking measurement defect is open. See
[`../docs/KNOWN_ISSUES.md`](../docs/KNOWN_ISSUES.md) for the full evidence
chain and reproduction commands.

Summary: in the canonical panel, the outcome `Z_belief_outcome` is an exact
linear rescaling of the predictor `C_cultural_intensity` (`corr = 1.0`,
max abs difference `4.4e-15`). The root cause is a WVS ingestion error: `C`
was built from item `A006`, which is also the first item of `Z`, instead of
from its configured item set `A008, A009, E012, E015, E018`.

Consequences:

- every out-of-sample metric reported in `main.tex` is algebraically
  guaranteed, not empirically estimated;
- the C-dominance diagnostics (Table S18) describe the defect rather than a
  substantive finding.

The numbers in `main.tex` must be regenerated after the ingestion is fixed.
Do not submit the current PDF.

```bash
cd paper/main

```

## Known LaTeX warnings

(`fig:main-function-views`, `tab:panel_fit_headline`,
`tab:marginal-effects-regimes`, `tab:preset-country-z`). Harmless for
typesetting, but should be resolved before submission.
