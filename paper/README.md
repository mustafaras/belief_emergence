# Manuscript Sources

LaTeX sources for:

> **Measurement Validity Before Model Geometry: A Reproducible Audit of
> Bounded Response Models**
> *Composite Constructs, Support Limits, and an Honest Model Comparison for Country Panels*

## Contents

| Path | Purpose |
|---|---|
| `main/main.tex` | Main manuscript source |
| `main/references.bib` | Bibliography (biblatex/biber, APA) |

Figure binaries for the supplementary file (~19 MB) are not versioned here.
They are regenerated by the analysis scripts at the repository root and
archived with the submission package. `supplementary_materials.tex` will not
build in a clean clone until those figures are restored.

## Current status: measurement defect resolved, submission gate CONDITIONAL

The blocking defect described in earlier versions of this file is closed. The
construct layer was rebuilt from raw WVS microdata by
`scripts/build_wvs_constructs.ts`, and `scripts/verify_constructs.ts` re-derives
every audit number independently.

What was wrong, in one sentence: `C_cultural_intensity` was built from item
`A006` — the first item of the outcome `Z` — so `corr(Z, C) = 1.0` and every
reported fit was an algebraic identity.

What is now true:

- `Z` reaches `alpha = 0.8187` over 287 country-years and is retained;
- `C` (`0.3482`), `D` (`-1.2285`) and `S` (uncomputable) fail the reliability
  floor and are **declared but not estimated**; the model runs on seven columns;
- the canonical panel is 87 complete-case country-years, 48 countries,
  1990–2022, with no scenario replication;
- in-sample `R² = 0.3854`; the saturating form loses to a linear baseline
  (0.10 vs 0.20);
- primary out-of-sample evidence is repeated grouped k-fold
  (`cv_kfold.json`): 100 folds, median held-out `R²` 0.2707 / 0.2790 / 0.2617 for
  Tier A/B/C, leakage none, `R²` defined in every fold. Country-out is retained
  as a spatial stress test; its per-fold median is negative only because 36 of
  48 folds hold fewer than three rows, and its pooled series is positive
  (0.3026 / 0.2579 / 0.2724);
- `npm run q1:gate` returns **READY 24/24**.

See [`../docs/KNOWN_ISSUES.md`](../docs/KNOWN_ISSUES.md) for the itemised
history and [`../docs/ROADMAP_TO_SUBMISSION.md`](../docs/ROADMAP_TO_SUBMISSION.md)
for what remains open.
